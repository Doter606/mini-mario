# 🎮 Mini Mario Edition

Мини-платформер в стиле классического Mario на Python + Pygame.


Возможности

4 уровня с растущей сложностью + комната босса
Классические кирпичи в стиле Mario (со бликами и стыками)
Зелёный слизень — патрулирует платформы, разворачивается на краю
Фиолетовый слизень — прыгает раз в 3 секунды, не прыгает в яму
Босс-дракончик — 8 HP, 4 атаки, режим ярости при HP меньше 3
Монеты — счётчик на HUD
Система ключей — убить босса → получить ключ → открыть клетку с флагом
Портал — переход в комнату босса после 3-го уровня

Управление
 ← / A / Движение влево 
 → / D / Движение вправо 
 ПРОБЕЛ / ↑ / W / Прыжок 
 R / Рестарт игры 
 ESC / Выход 

Установка и запуск
1. Установить Python

2. Установить Pygame

3. Ввести: pip install pygame   /   python -m pip install pygame

4. Запустить игру
python main.py
